# Implementation status

## Included in this starter
- Compose-based Android screens for dashboard, transactions, family events, loans/EMI estimates, and management data.
- Local Room database.
- App splash branding and logo vector.
- GitHub Actions debug APK workflow.
- Firebase setup plan and restrictive starter rules.

## Not yet implemented/verified
- Firebase Email/Password sign-in and password reset.
- SMS OTP sign-in (requires Firebase Phone provider and device/number testing).
- Firestore cloud sync and multi-device conflict handling.
- Full Gujarati/Hindi/English translation of every screen.
- Push notifications or scheduled EMI notifications.
- Automated UI/instrumentation tests and a successful real Android build on a configured SDK runner.

Do not describe this package as production-ready until these items are implemented and tested.
