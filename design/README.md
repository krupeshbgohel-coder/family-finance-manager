# Family Finance Manager — design assets

- `app-design-preview.png`: visual concept board showing logo, splash, language, login, dashboard and feature screens. This is a design preview image, not a set of implemented screenshots.
- `app/src/main/res/drawable/ic_family_finance_logo.xml`: scalable Android vector logo.
- The app opens with a branded Compose splash screen before showing the finance dashboard.

Important: The current app implementation includes dashboard, activity, events, loans and manage screens. The visual preview also illustrates planned screens (login, language selection, full charts/reports) that are not yet implemented. Firebase login/cloud sync are not enabled.
